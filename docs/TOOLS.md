# teamcraft MCP tools

Generated by `teamcraft tools --markdown`. Do not edit by hand: a test fails when this file
is out of date. Every tool is also a CLI verb (`teamcraft --help`). Dotted names (`app.verb`) are accepted.

| Tool | What it does | Required | Optional |
|---|---|---|---|
| `team_status` | Counts (active employees, clocked in, open leave requests, active AZG findings) and who is clocked in now. | - | - |
| `team_employee_add` | Add an employee. Only work-relevant fields; no SV number, address or bank data. | `code`, `name` | `kv_group`, `kv_name`, `leave_days`, `monthly_gross`, `start_date`, `weekly_hours` |
| `team_employee_list` | List employees. | - | `include_inactive` |
| `team_employee_update` | Change employee fields; null clears kv_name/kv_group/monthly_gross. active=false retires an employee. | `code` | `active`, `kv_group`, `kv_name`, `leave_days`, `monthly_gross`, `name`, `weekly_hours` |
| `team_clock_in` | Start a time entry (one open entry per employee). | `employee` | `at`, `note` |
| `team_clock_out` | Close the open entry with break minutes. | `employee` | `at`, `break_minutes` |
| `team_time_add` | Record a past entry. start/end as HH:MM with date, or full date-times. An end before the start on the same date means a night shift. | `employee`, `start`, `end` | `break_minutes`, `date`, `note` |
| `team_time_list` | Entries and daily totals in a date range. | `from`, `to` | `employee` |
| `team_time_delete` | Delete an entry (refused in confirmed weeks). | `id` | - |
| `team_week_confirm` | Employee confirms an ISO week (2026-W45). Its entries become read-only. | `employee`, `week` | - |
| `team_azg_check` | Check working-time law (10h/12h daily, 60h weekly, 48h 17-week average, 30 min break above 6h, 11h rest). Findings are recorded, never auto-corrected. | `from`, `to` | `employee` |
| `team_violations` | Recorded AZG findings; cleared ones only with include_cleared. | - | `employee`, `include_cleared` |
| `team_leave_request` | Request leave. Days counted Mon-Fri minus Austrian public holidays. Sick leave is recorded directly and takes no note (no health data). | `employee`, `kind`, `from` | `half_day`, `note`, `to` |
| `team_leave_decide` | Approve or reject a request. Approving vacation beyond the balance needs force=true. | `id`, `approve` | `force` |
| `team_leave_cancel` | Cancel a requested or approved leave. | `id` | - |
| `team_leave_list` | Leaves, optionally by employee, year and status. | - | `employee`, `status`, `year` |
| `team_leave_balance` | Vacation entitlement (pro rata in the start year), taken, pending, remaining; sick/comp/unpaid day counts. | - | `employee`, `year` |
| `team_leave_adjust` | Add or subtract vacation days for a year (carry-over etc.), with a reason. | `employee`, `year`, `days`, `reason` | - |
| `team_holidays` | Austrian national public holidays of a year. | - | `year` |
| `team_kv_import` | Import KV minimum wages from CSV kv;group;valid_from;monthly_min;weekly_hours. The table is yours: no KV figures ship with the app. | `path` | - |
| `team_kv_list` | KV minimum table. | - | - |
| `team_kv_check` | Compare each employee's gross with the KV minimum valid on a date, pro rata to weekly hours. | - | `date` |
| `team_timesheet` | Monthly working-time record (AZG section 26): per day start/end/break/worked/absence/holiday/AZG flags, worked vs target. path writes a semicolon CSV. | `employee`, `month` | `path` |
| `team_capacity` | Available hours per employee for an ISO week after holidays and approved leave. emit=true sends capacity.changed to taskcraft. | - | `emit`, `week` |
| `team_drain_inbox` | Open one employee per hirecraft candidate.hired event. The code is the candidate id reduced to 1-8 letters or digits. Salary is not copied. A repeated candidate is skipped. A payload without candidate_id or name is rejected. | - | - |
| `team_demo_seed` | Fill an EMPTY database with a labelled demo team, fictional KV table and deliberate AZG findings. | - | - |
