# Changelog

## 0.2.0 - 2026-11-12

- Desktop window rebuilt on `craft_biz_ui::app::Shell` (the earlier window bypassed dispatch): time clock, timesheet, absence calendar, leave request board, balances, capacity, AZG checks, team and KV check, settings. All 25 tools reachable (coverage test); 6 window tests incl. a real board drag.
- Store: `open_entries()` lists every open entry; the window no longer hides clock-ins older than 31 days.
- Core: timesheet rows carry `target_minutes`, so the window shows target and balance to date in the running month.
- Absence calendar: equal cells, today as a column band, kind letters and half-day marks (not colour alone).
- AZG rule codes shown in words (DE/EN); weekday names follow the window language.
